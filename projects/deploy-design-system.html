Overview

Hive is now Deploy.

In October 2026, Hive rebranded as Deploy, an AI inference platform for developers and enterprises. The brand, platform and website changed at the same time.

We rebuilt the design system for the new brand. One system now serves both the Portal and the marketing site, and we worked with frontend engineers through handoff.

thehive.ai → deploy.com

The problem

Hive's system didn't fit Deploy

It was built for trust and safety dashboards. Deploy needed a system for a developer platform, a new website and a model catalog.

Auditing Hive

What we started with

Hive had primitive and semantic tokens, but only for a light theme. There was no dark mode.

The type was Roboto, which made the products look dated. We took on the challenge of modernising them for Deploy.
